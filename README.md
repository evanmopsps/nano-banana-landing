# 🍌 Nano Banana Landing Page

A polished, responsive static landing page for **Nano Banana** - Google's Gemini-powered image generation and editing model.

## 🌟 Features

This landing page showcases:

- **Text-to-Image Generation** - Transform words into stunning visual art
- **Advanced Image Editing** - AI-powered editing with natural language
- **Character Consistency** - Maintain character appearance across images
- **Lightning-Fast Generation** - Rapid results without quality compromise

## 🚢 Deployment

This site is designed to be hosted on GitHub Pages:

1. Push to the `main` branch
2. Enable GitHub Pages in repository settings
3. Set source to "Deploy from branch: main / (root)"
4. Site will be live at `https://<username>.github.io/<repo-name>/`

The `.nojekyll` file ensures GitHub Pages serves the site correctly without Jekyll processing.
